# Hisab Studio 2 1.0.25 (test build)

- Ask Hisab run tree: 11 blocks, one colour each, coloured lines with a travelling dot, per-block animation.
- Strictly driven by the real run steps (node, text, microseconds). Display pacing about 0.35 to 0.42 s per block; the engine takes about 20 ms. Blocks on a level run one after another.
- Sources list under answers, mic button, "Hisab mode" line, switch "Show the steps while answering".
- Home: animated "Hisab AI" pill that opens Ask Hisab.
- Size about 4.6 MB. No model, no network, no new permissions.
- Not tested on a real phone. GPL-3.0.
